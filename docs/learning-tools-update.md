# Practice reminders and understanding-based training

The curriculum now contains 104 lessons and 2,506 puzzles. The additions are 12 authored guided demonstrations, 12 originally written advanced lessons using distinct existing CC0 source positions, and 96 original checkmate-in-one drills across rook, queen, bishop, knight, pawn and promotion families. The generator checks that the opponent is not already in check and that each drill has exactly one legal mating move. Puzzle difficulty remains a training estimate, separate from external ratings.

After solving a puzzle, Explain your move asks a multiple-choice question derived from the actual played line. It checks board facts such as checkmate versus stalemate, a knight fork's targets, promotion, escaping check, checks and captures. These facts do not pretend to be complete engine analysis. Wrong answers receive feedback and can be retried; the first-try understanding result is saved separately from the chess-move result. Settings can disable the extra question. Every completed exercise includes legal solution replay with previous/next controls.

Learners can bookmark lessons and puzzles for the Saved practice shelf. Puzzle filters include unseen, most recently missed, saved and the new original drills. Home provides links to the shelf, reminders and new content.

Reminder preferences are opt-in, saved with progress, and include local time and chosen weekdays. In-app reminders offer Start, ten-minute snooze and dismiss-for-today; they do not nudge after recorded practice that day. Add to my calendar exports a recurring RFC 5545 event with a display alarm, local floating time and a link to lessons. The learner must import it and confirm their calendar's alert settings. This is not a background Web Push service; in-app nudges require the app to be open. Previously imported calendar events must be removed when replacing a schedule.

Validation: 86 automated tests pass, including all lesson/solution legality, unique mates, explanation replay for every puzzle, reminder due/dismiss/snooze behavior, calendar recurrence/alarm generation, and progress serialization. TypeScript passes. Browser checks verified editing and retaining a 19:30 reminder after reload, a real top-level calendar download containing the selected recurrence and alarm, puzzle explanation retry/save, solution replay, bookmark persistence, the 96-position filter, narrow 320 px layout, and completion of an added lesson. The time input uses both input/change events to retain native picker edits consistently. Temporary device-check HTML is removed before publication.
