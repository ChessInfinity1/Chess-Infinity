# Chess Infinity

A working chess training application built with React, TypeScript, Vinext/Next-compatible routing, chess.js, Stockfish 19 Lite in a Web Worker, and Cloudflare D1. Private hosted access uses ChatGPT sign-in; external chess connections do not replace that identity.

## Working features

- Original responsive dashboard, floating liquid-glass mobile navigation, dark mode, three board palettes, and original SVG pieces. The mobile dock respects safe areas and keyboard visibility, and supports a solid fallback for browsers without backdrop filtering.
- Legal tap/drag chessboard, move highlighting, check detection, promotion choice, castling, en passant, board flipping, right-click annotations, keyboard square navigation, and animated moves.
- 80 interactive lessons with original teaching and quizzes, 2,410 validated tactical exercises (10 original and a CC0 subset of 2,400 Lichess puzzles), hints, quizzes, lesson completion, XP, daily activity, streaks, internal Elo-style puzzle difficulty, and spaced review dates.
- 24 original opening introductions with legal replayable lines, plans, mistakes to avoid, saved repertoires, recall practice, and live continuation statistics from the documented Lichess opening-explorer endpoint when available/authorized.
- Local Stockfish opponents with skill settings and training clocks; takebacks and blindfold practice.
- PGN/FEN import/export, legal move replay, real background engine evaluation, principal variations, full-game reviews, evaluation graphs, transparent accuracy estimates, and critical moments.
- Save engine findings into a practice queue built from the actual pre-move positions, plus a recurring-theme summary. Coach suggestions are rule-based and clearly distinguished from engine findings.
- Real Chess.com public profiles open an accessible detail sheet after linking: avatar, public identity/location/membership details, available ratings and bests, win/draw/loss records, puzzle records, and searchable/filterable games with analysis links. Imports are serial and legally validated, with pages of up to 40 completed standard games. Month-and-offset cursors preserve every game within a monthly archive and allow browsing older history. No Chess.com password or authenticated ownership is claimed. The newest 150 imported games remain in saved progress; the profile sheet can browse additional older pages during the session.
- Lichess authorization-code PKCE flow using S256, state checking, no optional scopes, an HttpOnly/Secure/SameSite=Lax token cookie, authorized account/game imports, and token revocation. No passwords or tokens are placed in application JavaScript or D1 progress records.
- Seven-piece endgame tablebase lookup with theoretical result and DTZ.
- D1 user-isolated persistence with optimistic concurrency, automatic saves/retries, device-local pending backups, explicit conflict recovery, data export, and deletion.
- Full-screen install manifest, a real browser full-screen control, theme-matched chrome, and a self-contained offline training download with lessons, puzzles and arcade modes. Private account pages and APIs still need a connection and are never cached.

## Development

Use Node.js 24. Install and run via the platform helpers described in `docs/PLATFORM.md`. Build with `npm run build`. Run `npm run typecheck` and `npm test`. The tracked D1 migration is applied on deployment; local D1 migration commands are documented in `docs/PLATFORM.md`.

Modules: `components/chess/` (dashboard, board, training, review), `lib/chess/` (content, engine, providers), `lib/progress-store.ts` (concurrent persistence), `app/api/` (authenticated progress and integrations), and `db/` (schema/binding). Content uses typed lesson, puzzle, and opening records; expansion does not require changing board rules or progression logic.

## Calculation methods

Engine scores use White's perspective. Checkmate is assigned ±100 pawns internally; draw positions score 0. Per-move losses clamp scores to ±10 for the approximate accuracy formula. Playing the engine's preferred move has zero loss. Accuracy = mean(100 × exp(−loss in pawns / 3)). Best = engine first choice; Excellent <0.15 pawn loss; Good <0.5; Inaccuracy <1; Mistake <2; Blunder ≥2. Search duration and depth affect all estimates. Great and Brilliant are deliberately not classified in this release.

Puzzle rating starts at 600. Each recorded result uses K=32 and expected score 1/(1+10^((exerciseDifficulty−playerRating)/400)); hints/wrong moves prevent a clean result. Original exercise difficulties are authored training estimates; Lichess puzzles retain their source puzzle rating. Neither is an external player rating. XP is capped to one award per lesson and one award per puzzle per UTC day. Saved repertoire review intervals double after successful recall, capped at 30 days; failed exercise reviews return after one day. Streak dates use the visitor's browser-local day.

## Remaining roadmap

This is a usable first release, not the entire exhaustive product brief. Advanced tracks currently contain foundational drills. Thousands of lessons, the complete multi-million-position puzzle database, full opening trees with authored master-game examples, online arcade competitions, complete endgame masterclasses, tournament preparation, cloud background analysis jobs, multi-PV/resizable analysis layouts, premoves, external study/puzzle imports, full historical ratings, opt-in leaderboards, and a language-model conversational coach remain unimplemented. No controls pretend that these services are connected.

External requests respect provider failures and never fabricate ratings, games, or evaluations. Use analysis only for training and completed games. Current data storage is bounded (150 games, 20 saved analysis reports with up to 60 critical moments each, and 2,000 puzzle attempts); larger production deployments should normalize these records into dedicated tables and background import jobs.

## Installable app and training arcade

Install & offline in the sidebar provides the actual browser install prompt where supported, installation steps for Android, iOS/iPadOS and desktop, and an in-app browser notice. The authenticated manifest is requested with credentials. Installation state uses the browser appinstalled event or installed display mode; accepting a prompt alone never marks installation complete. Browser installation is not an APK or app-store distribution.

The optional offline pack is independently bundled React/chess.js training content, not cached authenticated pages. Download verifies every asset and the matching application version before marking the pack ready; an unsuccessful update preserves the previous complete pack. Lessons, puzzles, arcade runs, and record export work locally. Importing records writes the account/device backup before clearing the offline queue; the normal optimistic cloud-save flow handles uploads. Duplicate imports do not duplicate XP. Private account pages, API responses and tokens are never service-worker cached. Online imports and full engine review still need a connection. Browsers may clear downloaded storage.

The arcade adds a three-minute Puzzle Sprint, untimed three-life Survival, 60-second Board Vision, a deterministic daily puzzle, best scores, missed-position practice and three earned milestones. Tactical sessions use 2,400 source puzzles plus forty legal transformations of the original ten patterns. The deck is exhausted before repeating within a mounted arcade session; it is a selected subset, not the complete Lichess database. Incorrect legal moves, hints and skips make a solve assisted; only clean solves add to the session score. Survival hints and skips cost lives. Arcade XP is five per clean score, up to 50 per result and 150 per browser-local day within retained history. Arcade history retains 30 sessions, independently of external chess ratings.

Validation for this update covers 40 legal transformed solutions, transformed en passant/promotion, puzzle move checking, score and import idempotence, offline asset completeness, canonical hosting redirects, deployment version mismatches, failure recovery, API cache exclusion and browser-platform guidance.
